## 4. 功能清单

### 直播层（真实数据）
- 播放：频道 YOUR_CHANNEL_ID 回放画面（`watchCore.player`）
- 聊天：历史消息 / 实时消息 / 发送（`watchCore.chat`）
- 点赞：`sendLike` + 实时点赞数
- 状态：在线观看数、`liveStatus` 自动切换 LIVE/回放中

### 宠物层（29/29 素材）
- 全身形象，可拖拽、点击跳、双击转身（正面 → 3/4 → 侧 → 背）
- 待机：呼吸摆动 + 每 7s 正脸/3-4 视角轮换
- 表情：眨眼 / 微笑 / 大笑 / 惊讶 / 疑惑 / 思考 / 委屈 / 得意 / 托腮
- 动作：指向（左/右）、举手、鼓掌、比心、庆祝、摊手、挥手
- 口型：A/I/U/E/O 循环，与 AI 流式文字同步
- 程序化动作：转圈（礼物）、鞠躬/挥手（关注）、跳舞（连击）
- 亲密度：点击/点赞/发言累加

### 事件层
- 模拟事件（工具栏「🧪 事件」）：答题卡 / 观众提问 / 签到 / 抽奖
- **真实事件**：`interactReceive.setupIarCore()` 后监听
  - 答题卡：`GET_TEST_QUESTION_CONTENT` → 气泡出题；`answerQuestion()` 提交；`GET_TEST_QUESTION_RESULT` 出结果
  - 签到：`SIGN_IN` → 气泡签到；`toCheckIn()`；`SIGN_IN_SUCCESS`
  - 抽奖：`LotteryStart`/`OnLottery` → 气泡参与
  - 公告：`BULLETIN` → 气泡展示
- 无真实事件时可用 `window.__iarDemo.quiz()/checkin()/lottery()/announcement()` 调试真实 UI 流程

### AI 层
- 保利威 AI 答疑助手（知识库 RAG）+ DeepSeek（闲聊）混合路由
- SSE 流式返回，驱动打字与口型
- 失败回退本地话术
- 密钥全部服务端；Origin 白名单 + 限流

## 6. 素材生产管线

1. 按 [人物素材-v2/README.md] 与 prompts 生成 1184×1328 白底/透明 PNG
2. 丢进 `人物素材-v2/inbox/<slot>.png`
3. `python3 demo/tools/check-inbox.py` 自检（尺寸/透明/内容高度/脚底线）
4. `python3 demo/tools/build-frames.py`
   - 抠白底 → 去白边 → 高度 512 → 胯部中心对齐 → 底对齐 512×512
   - 更新 `assets/full-<slot>.png`、`full-manifest.json`、`slots.json`
5. demo 自动启用；`preview.html` 刷新看板

当前：**29/29**，全部 512×512。

## 8. 已知限制与风险

1. **示例频道需为「公开观看」或白名单/独立授权**，否则 SDK 授权会走 fallback。
2. **保利威问答接口** `/ai/v1/chat/question` 是官方聊天 iframe 内部接口，未公开文档；上线前建议与保利威确认授权与稳定性。
3. **真实互动事件已接线但未用真实场次验证**（需发起一次真实答题卡/签到/抽奖联调）。
4. **白底边缘**已做去白边处理，但发丝内部封闭白洞仍有轻微残留；放大可见，172px 下不明显。
5. 素材为 2D 帧，动作幅度有限；长期建议 Live2D 或 Tripo 3D。
6. 演示如需 DeepSeek，请使用你自己的企业 Key，并放在服务端环境变量里。
