# 人物素材 v2 · 投图即用

> 你只需要把 **PNG 丢进 `inbox/`**，命名按 `manifest.json` 的 id（例如 `neutral.png`、`point-left.png`），然后运行一条命令，demo 会自动用上新动作。

## 硬性要求（不满足会穿帮）

- 同一机位、同一比例、**脚底线一致**（关键：所有图里鞋底在同一条水平线）
- 透明背景（或纯白底，脚本会自动抠白）
- 单张 **≥1024px 高**，无阴影、无地面、无文字水印
- 每张只放一个角色，正面/3/4/侧背按 slot 命名

## 目录

```
人物素材-v2/
├── manifest.json     # 所有槽位：id / 说明 / 目标文件 / 是否已就绪
├── inbox/            # 你把 PNG 放这里，文件名 = slot id
└── README.md
```

## 处理命令

```bash
# 在项目根目录
python3 demo/tools/build-frames.py
```

脚本会：抠白底 → 去空白 → 统一高度 512 → 底对齐画布 512×512 → 输出到
`demo/assets/full-<id>.png`，并更新 `manifest.json` 的 `available`。

## 优先级（先做这些就能跑事件互动）

1. `point-left`（气泡在左侧，答题时指题）
2. `celebrate`（答对）
3. `shrug`（答错）
4. `raise-hand`（提问）
5. `clap`（签到）、`heart`（点赞）
6. 其余表情/口型/3/4 视角按需补

## 生成提示词建议（给 Codex / image_gen）

以 `参考图/` 里的正面全身图为唯一角色基准，逐张生成，并强调：

```
Use the attached full-body character as the exact identity/proportion/outfit reference.
Same camera, same full-body framing, same feet baseline, same scale, transparent or pure white background.
Change ONLY the pose/expression: <具体动作，例如 "right arm raised and pointing to the left, other hand on hip">.
Keep hair, O hair accessory, headset, POLYV badge, tail, skirt identical.
No background scene, no shadow, no extra characters, no text.
```

> 一致性优先：宁可动作幅度小一点，也不要改变角色比例/服装/发饰。
