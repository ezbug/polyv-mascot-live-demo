# 动作素材生成 Prompt 包

> 用法：附上 **角色基准图**（`3D制作/静模样片-v01/inputs/front.png` 或 `建模设定/保利威娘-v01-放大O发饰/01-正面A姿态-放大O发饰.png`），把下面的「通用前缀 + 动作句」一起发给 image_gen。
> 生成后存成 `inbox/<id>.png`，跑 `python3 demo/tools/build-frames.py` 即可。

## 通用前缀（每次都要带）

```
Use the attached image as the EXACT character identity reference: same chibi proportions,
same royal-blue long hair with light-blue tips, cat ears, cat tail, blue-and-white uniform,
white V collar, POLYV chest badge, O-shaped play-button hair accessory, blue-white headset
with microphone. Do not redesign, recolor or add anything.

Same camera: front view, eye level. Same full-body framing and scale: hair tip to shoe soles
fully visible with a small margin, character centered, feet flat on the SAME horizontal
baseline as the reference. Transparent background (or pure white if transparency is not
supported). No ground, no shadow, no background scene, no text, no watermark, no extra
characters. One single character.

Change ONLY the pose/expression described below. Keep face, hair, outfit, accessories and
tail identical to the reference. Keep the same soft Japanese chibi illustration finish.
```

## 动作句（替换到前缀后面）

| id | 中文 | 动作句（追加） |
| --- | --- | --- |
| `celebrate` | 庆祝 | Both arms raised up in a happy V shape, open-mouth smile, eyes bright, standing with feet still on the baseline. |
| `shrug` | 摊手 | Both arms out to the sides with palms facing up, shoulders slightly raised, head tilted, awkward-but-cute smile. |
| `raise-hand` | 举手 | Right arm raised straight up with an open hand (like volunteering), left hand at the side, eager bright expression. |
| `clap` | 鼓掌 | Both hands together in front of the chest, clapping, happy closed-mouth smile, eyes curved. |
| `heart` | 比心 | Both hands forming a heart shape in front of the chest, shy smile with slight blush. |
| `point-right` | 指向右 | Right arm extended horizontally pointing to the viewer's right, left hand on hip, confident smile. |
| `wave` | 挥手 | One hand raised beside the head, waving, warm smile. |
| `chin` | 托腮 | One hand supporting the chin, listening attentively, gentle smile. |
| `laugh` | 大笑 | Mouth wide open laughing, eyes closed in a happy arc, head slightly back, hands relaxed. |
| `surprise` | 惊讶 | Eyes wide open, small round open mouth, hands slightly raised beside the body. |
| `confused` | 疑惑 | Head tilted to one side, one eyebrow raised, one hand near the cheek, puzzled expression. |
| `think` | 思考 | One hand on the chin, eyes looking slightly upward, thoughtful expression. |
| `sad` | 委屈 | Eyes slightly down, small frown, hands held together in front of the waist. |
| `proud` | 得意 | Both hands on hips, chest out, confident proud smile. |

## 口型（可选，用于全身说话）

在 `neutral` 基础上只改嘴：

| id | 口型 |
| --- | --- |
| `A` | Mouth wide open as if saying "Ah". |
| `I` | Mouth stretched horizontally as if saying "Ee". |
| `U` | Lips rounded and pushed forward as if saying "Oo". |
| `E` | Mouth half open as if saying "Eh". |
| `O` | Mouth rounded as if saying "Oh". |

## 3/4 视角（可选）

把前缀里的 `Same camera: front view` 改成：

```
Same camera: three-quarter front-left view (about 30 degrees), same full-body framing,
scale and feet baseline.
```

再配 `celebrate` / `smile` / `point-right` 等动作句。

## 转身视图（可选）

- 左侧身：`Same character, exact left side profile view, neutral standing pose, same full-body framing, scale and feet baseline.`
- 背身：`Same character, exact back view, neutral standing pose, same full-body framing, scale and feet baseline.`

## 负面提示（如果模型支持）

```
no background, no floor, no shadow, no text, no watermark, no extra limbs, no different outfit,
no different hair color, no 3D render, no realistic style
```
