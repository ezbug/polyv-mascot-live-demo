# 吉祥物「小威」直播间事件互动设计

> 目标：宠物不只是挂件，而是直播间的「互动主持人」——直播里发生答题卡、问卷、提问、签到、抽奖时，小威主动冒气泡、做动作、把交互收进气泡里完成。

## 一、事件 → 宠物行为

| 直播间事件 | 宠物动作 | 气泡内容 | 用户可做什么 |
| --- | --- | --- | --- |
| 答题卡开始 | 跳一下 + 举手指向气泡 | 题面 + 选项（≤4 个） | 直接点选项，答对/答错即时反馈 |
| 答题结果公布 | 答对：庆祝跳 + 笑脸；答错：眨眼摇头 + 摊手 | 「答对啦 / 差一点，答案是 D」 | 关闭或看解析 |
| 问卷 / 报名表 | 托腮思考 → 指向 | 迷你表单（姓名/手机/2-3 项选择） | 气泡内填写提交 |
| 观众提问（@助教/提问区） | 举手 + 「有同学提问」 | 问题摘要 + 「让小威回答 / 先忽略」 | 点回答 → 打开 AI 对话并自动追问 |
| 签到 | 鼓掌 / 跳舞 | 「签到成功 +1」 | 一键签到 |
| 抽奖开始 | 惊讶（`surprise`） | 「抽奖开始，要参加吗？」 | 参与 / 忽略 |
| 公告发布 | 指向公告 | 公告摘要 + 「知道了」 | 展开全文 |
| 点赞 / 打赏 | 比心 / 庆祝 | 「谢谢老板！」飘心 | 无 |
| 直播开始 / 结束 | 挥手 / 鞠躬 | 「马上开始啦」「下次见」 | 无 |
| 无直播 / 等待 | 待机呼吸、偶尔眨眼 | 不主动打扰 | 可点开聊天 |

## 二、交互规则

- 同一时间只显示一个事件气泡；事件按优先级排队：答题卡 > 抽奖 > 问卷 > 提问 > 公告 > 闲聊
- 答题卡进行中，其他事件不打断；用户答题后 4s 自动收起
- 气泡不遮挡播放器控制条；出现时宠物做一次动作 + 气泡弹入（0.2s）
- 气泡最大 252px 宽、屏内右侧、可手动关闭；移动端避开输入框
- 文字用「小威」口吻，短句；答错不打击，给正确答案 + 鼓励

## 三、技术接入

- **事件源**：观看页 SDK 的互动接收端事件（答题卡/问卷/签到/抽奖/公告/提问），转成内部事件总线
  `watchCore` / `@polyv/interactions-receive-sdk` → `window.dispatchEvent(new CustomEvent('pet:event', {detail}))`
- **宠物层**：订阅事件 → 播放动作（帧动画）→ 渲染气泡 → 回传用户操作（提交答案/表单/AI 提问）
- **AI 层**：提问事件复用现有 `/api/ai`（保利威知识库 + DeepSeek 闲聊）
- 当前 demo 里用「🧪 事件」按钮模拟事件流；真实接入下一步替换成 SDK 事件

## 四、需要你提供的人物素材

### 方案 A：2D 帧动画（当前 demo 用的，最快）

要求：**同一相机、同一比例、同一脚底线、透明底、单张 ≥1024px 高、无阴影/背景**。

| 类别 | 具体内容 | 数量 |
| --- | --- | --- |
| 基础 | 全身正面 A-pose（中性） | 1 |
| 表情（正面） | 中性 / 微笑 / 大笑 / 眨眼 / 惊讶 / 疑惑 / 思考 / 委屈 / 得意 | 9 |
| 口型（正面） | A / I / U / E / O（或单独嘴部条） | 5 |
| 动作（正面） | 指向左侧、指向右侧、举手、比心、鼓掌、庆祝跳、摊手、托腮、挥手 | 9 |
| 3/4 视角 | 中性 + 微笑 + 指向 + 庆祝（气泡在侧边时更自然） | 4 |
| 转身（可选） | 左侧身、背身（中性即可） | 2 |
| UI | 气泡底板（可选，9-slice PNG）、答题卡卡片、选项按钮、对/错图标 | 1 套 |

### 方案 B：Live2D（推荐，动作最自然）

- 分层 PSD：前发/后发、脸、眼白/瞳孔/高光、眉毛、嘴、身体、左右手臂、尾巴、O 发饰、耳麦
- 每个部件单独图层、命名规范；口型与表情做参数（ParamMouthOpen、ParamEyeLOpen 等）
- 需要你的画师按 Live2D 规范拆层（现有插画不能直接拆）

### 方案 C：3D（Tripo 模型，适合长期）

- GLB/VRM + 骨骼绑定 + 表情 morph（喜/怒/哀/惊/眨眼/口型）
- 动画剪辑：idle / wave / point / think / celebrate / bow
- Tripo 生成的是静态模型，需要再绑定骨骼与表情（Blender 可做）

### 最省事的组合（建议）

先用 **方案 A 的 9 表情 + 9 动作（正面）** 把事件互动跑通；等 Tripo 模型绑定好，再整体升级成 3D（three.js 播放动作），气泡与事件逻辑不用改。

## 五、当前 demo 已实现

- 全身形象：待机呼吸/摆动、眨眼、口型说话、点击跳、双击转身
- 程序化动作（不需要新图）：转圈（礼物）、鞠躬（关注）、跳舞（点赞/签到）
- 素材已齐：29/29（含 proud、3/4 视角 q-neutral/q-smile/q-point/q-celebrate）
- 素材进度：29/29 帧可用（表情、口型、动作、转身、3/4 视角全齐）
- 事件气泡：答题卡（4 选项、对错反馈、宠物庆祝/摇头）、观众提问（一键转 AI 回答）
- 触发方式：工具栏「🧪 事件」模拟；下一步接真实 SDK 互动事件
